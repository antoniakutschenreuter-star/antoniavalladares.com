Tegernsee — Wunderschöne Regenhochzeit am See

Tegernsee, Oberbayern

Wunderschöne Regenhochzeit am See

Regen macht eine Hochzeit nicht kleiner, er macht sie weicher. Das Licht wird ruhig, die Farben werden satt, und unter zwei schwarzen Schirmen entsteht eine Nähe, die an einem strahlenden Tag so nie zustande käme. Wer sich vorher auf einheitliche Schirme einigt, bekommt statt eines Notfalls ein Bildmotiv.
